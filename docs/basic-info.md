# Toyo Basic Info

このファイルは、このプロジェクトで繰り返し参照しそうな基本情報をまとめるための手動ドキュメントです。

自動生成される履修データとは役割を分けます。

- 固定寄りの情報: 公式リンク、時限、キャンパスアクセス、入構ルール
- その時点の登録状況: `output/toyo/registration-summary.md` と `output/toyo/registration-data.json`

## まず見る場所

- 履修まとめ: `output/toyo/registration-summary.md`
- 構造化データ: `output/toyo/registration-data.json`
- 時間割ファイル: `output/spreadsheet/toyo-timetable.xlsx`

## 入構時の基本

東洋大学公式案内では、在学生は入構時に次のいずれかを提示する。

- 東洋大学公式アプリ `TOYO-PASS`
- 学生証
- 大学が発行した身分証明書

初回やトラブル時に備えて、スマホだけに寄せすぎず、学生証も持てると安心。

## 初登校メモ

最低限の持ち物候補:

- スマホ
- `TOYO-PASS` または学生証
- 財布
- 交通系ICカード
- 筆記用具
- ノート
- 飲み物
- モバイルバッテリー
- 履修情報を確認できるもの

あると安心:

- PC
- 充電器
- クリアファイル

## 毎回の確認メモ

家を出る前に見る候補:

- ToyoNet-G
- 休講掲示板
- 履修データと当日の曜日
- 教室変更や連絡

授業についての公式案内では、休講情報は休講掲示板と ToyoNet-G に配信される。

## このドキュメントの更新方針

- 履修変更があったら、自動出力を更新してからこのファイルの要約も見直す
- 公式情報が変わりうる項目は、可能なら日付つきで更新する
- 迷ったら、固定情報はこのファイル、最新の登録内容は `output/toyo/` を正とする
